# 中文用语与语义核对

修改中文时读取。下表是本项目约定；完整现行译文仍以 `l10n/translations.json` 为准，不复制成第二份词表。

## 常用网盘用语

| 英文概念或消息键 | 推荐表达 | 边界 |
|---|---|---|
| Spaces / 产品中的 Space | 团队空间 | 不机械替换所有 `space`，存储容量和空白字符另译 |
| Personal | 个人空间 | 不写成“个人团队空间” |
| Deleted files / Trash 导航 | 回收站 | 描述“某文件已删除”的普通句子仍按动作翻译 |
| Share / Shares | 分享 | 依上下文补足对象；“取消分享”不等于删除文件 |
| Shared with me | 分享给我的 | 保持分享方向 |
| Shared with others | 我分享的 | 保持分享方向 |
| Public links | 公开分享链接 | 与成员权限、内部链接区分 |
| Groups | 用户组 | 不与团队空间或文件夹混用 |
| Members | 成员 | 角色名按真实权限区分 |
| Manager / Owner | 管理员 / 所有者 | 不合并权限角色；团队空间管理员不一定是系统管理员 |
| Restore | 恢复 | “移至回收站”“永久删除”分别表达原操作及后果 |
| Upload / Download | 上传 / 下载 | 不额外暗示自动同步 |

新增术语先查本词表中同一业务概念的上下文，选定表达后更新这里。示例表与真实译文有冲突时核对英文和使用位置，不批量覆盖整库。

## 文案习惯

- 按操作表达动作：如“创建团队空间”“移至回收站”“复制链接”；按钮用简短动词，结果提示说明发生了什么。
- 面向使用者，避免逐词照搬英语语序；必要主语、对象和限制不能因精简丢失。
- 权限、配额、到期、删除和公开访问相关文案保留适用范围与条件，不把“可以”译成“必须”，不把部分成功写成全部成功。
- 中文使用自然标点；文件名、产品名、协议名和变量保持原样，如 OpenCloud、WebDAV、OIDC。展示标点可以调整，消息键和占位符内部不能调整。
- 英文复数形式通常可合并为自然中文，但数量变量必须保留；不要在不知道运行时复数规则时改词表的数据结构。
- 无障碍标签仍应说明控件用途、当前状态或所在区域，不能为了短而改成只含图标名称。

## 代表性核对

| 英文 | 中文示例 | 检查点 |
|---|---|---|
| `"%{item}" was moved to trash bin` | `“%{item}”已移至回收站` | 是移入回收站，而非永久删除 |
| `%{ amount } item selected. Actions are available above the table.` | `已选中 %{ amount } 项。可在表格上方执行操作。` | 保留占位符内部空格和操作位置提示 |
| `%{used} of %{total} used (%{percentage}%)` | 按当前产品上下文说明已用量、总量及比例 | 三个变量不能因精简而遗漏 |

对歧义词，优先查看目标版本中的组件、翻译调用和实际页面。截图没有英文键时先查原始消息，不按中文反推并创建新键。参考国内产品的用语习惯，不直接复制整套第三方文案。
